Power Dialer & SQL Tag SOP

Two systems, one doc. The power dialer is how the team gets through volume fast. The SQL tag is how a lead a closer personally qualifies gets counted correctly instead of getting lost or double-counted. Built directly from the automations JJ and Khalil set up live on August 15 — this is the clean version, not the scattered version.

Why This Matters

Ad spend only works if Meta knows which leads actually turned into real, qualified booked calls. If every lead fires the same signal back to the pixel, Meta can't tell a good lead from a bad one, and the algorithm starts finding you more bad ones. The SQL tag is what protects that data. The power dialer is what gets you through enough leads fast enough for it to matter.

Daily Use — All Reps

Power Dialer

The power dialer takes a list ("bucket") of leads and rips through them one after another automatically, instead of you manually clicking dial on every single contact. This is the fix for what Micah was running into — dialing manually was eating her whole day.

Step by Step

1

Log into SendBlue

Everyone already has a login. If you don't, text Khalil.

2

Find your bucket

Your dial list lives under Conversations, not Settings. Buckets are built and named by Khalil — ask him which one is yours if you're not sure.

3

Hit dial and let it run

The power dialer moves straight down the list and connects you when someone picks up. You don't need to manually advance between calls.

⚠️ If Your Bucket Looks Wrong or Empty

There's a known bug where lead assignments don't always sync correctly from GHL into SendBlue, so a bucket can show the wrong leads or nobody's leads. This is not something you can fix yourself. Flag it to Khalil — the real fix runs through the SendBlue CSM (Simon or Maria). In the meantime, you can still dial manually: go to the Opportunities tab in GHL, use the SendBlue plug-in, and dial straight from the contact record.

Daily Use — All Closers

The SQL Tag — What It Is and When to Add It

High-credit leads get tracked automatically the moment they book through the priority calendar — you don't need to do anything for those. This tag is only for the other case: a lead who came in lower-quality (NQL) but who you personally qualified once you actually got them on the phone or on a call.

Where It Lives

app.gohighlevel.com — Contact Record
🏷 SQL
+ Add tag
On the contact record, in the tags field — type SQL and add it. That's the entire action on your end.

✅ The Rule

Lead came in as NQL, but once you talked to her, she's actually qualified? Add the SQL tag on her contact record in GHL. That's it. The automation behind it (see below) handles the rest — you don't need to do anything else.

⚠️ Only Tag What's True

This tag feeds directly back to Meta as a real booked-call signal. Only add it when she's genuinely qualified. Tagging loosely to "help the numbers" pollutes the exact data this whole system exists to protect.

Admin Setup — Khalil

Building a Dial List (Bucket)

This is how a new dial list gets created and scoped — for a webinar push, a re-engagement campaign, or any other reason the team needs a fresh list to work.

1

Tag the contacts in GHL first

Build a quick workflow that adds a custom value tag (e.g. "webinar") to everyone you want on the list. Run it against the contact list you're targeting.

2

Create the matching bucket in SendBlue

In SendBlue, go to Conversations → top right → create a new bucket. It works like a GHL smart list — a saved filter, not a static export.

3

Let it cross-reference

Once the tag exists in GHL and the bucket is built in SendBlue, it should pull the matching contacts in automatically — no manual list upload needed.

SQL Tag → Meta Conversion API Workflow

This is the automation that makes the closer's SQL tag actually mean something — it fires a real conversion event back to Meta the instant the tag gets added. Set up once, then it just runs.

Configuration Details That Matter

  • Change the event name from the default "Lead" to whatever your Hyros setup expects (FitMama uses "Schedule").
  • Leave the value field blank. Giving it a set value causes problems — don't add one.
  • Name the workflow something obvious — "Closer SQL to Meta" — so nobody has to guess what it does six months from now.
  • After building it, add a test tag to a dummy contact and confirm the event actually fires before trusting it live.

⚠️ If Data Quality Drops

Sending qualification data from GHL instead of directly through iClose can occasionally cause data drop-off. It's fine at FitMama's current volume. If your lead quality score in Ads Manager drops below a 7 or 8, that's the signal something's off — flag it and revisit.

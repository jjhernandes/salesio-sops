HYROX Training — Base Building Block

The Seven

Three strength sessions, running spread across the week, two station days. Seven sessions, not the twelve everyone tries to survive on. New to HYROX, already training hybrid — this block builds the station-specific skill and the aerobic engine on top of a base you already have.

The Guardrail

Don't tell yourself you're going to lift five days, run five days, add cross-training, and recover well from all of it — not without eating like it's a full-time job. Seven honest sessions beats twelve you can't recover from. If a day says optional, that's not a suggestion to skip guilt-free later, it's permission to read your fatigue and make the call in real time.

⚠️

Sunday's a real tradeoff, not a scheduling trick: the 9am HYROX class runs into Church at 9:30. You said the class wins on training weeks — so some Sundays you're skipping or shifting church. That's a call only you make, week to week, not something this doc solves.

Two Gyms, One Program — Which One, When

  1. Equipped gym (barbell, sled, SkiErg, wall balls) — Mon, Wed, Thu, Fri, 7am. This is where the actual programming happens. CrossFit's open gym is 1–4pm on weekdays, dead against your call schedule, so this membership isn't optional — it's the only access window that works.
  2. CrossFit — Sunday 9am class, non-negotiable. Live coaching on transitions beats anything scripted. Keep this no matter what else changes.
  3. CrossFit — Tuesday is the only swappable day. If a week's WOD looks aerobic-leaning, trade the solo easy run for the class. Check the WOD first — if it's max-effort strength or high-skill (Olympic lifts, gymnastics), skip it and run instead.
  4. Never stack a class on top of Mon/Wed/Thu/Fri. A WOD after a programmed session doesn't add fitness, it eats the recovery that session needed. That's the two-a-day trap — don't do it.

Week 2 — What's Different This Week

  1. Week 1 verdict: a real success. One session missed to sickness, not the program, everything else hit as written. That's exactly the outcome the 4-week hold is designed to produce, keep going.
  2. Saturday long run moves to 55–60 min (up from 50), per the standard +5–10 min/week bump for a week that recovered well.
  3. Add 5–10% load on any Monday/Wednesday/Friday lift where every rep of last week's top set was clean. If a lift wasn't clean across all reps, hold it at the same load and try again this week.
  4. Everything else in the block below stays exactly as written, that's the point of the 4-week hold, structure doesn't change, only the numbers above do.

Running It Forward

No race booked yet — here's how this block progresses

  1. Run this exact structure for 4 weeks before changing anything. Consistency is the variable that matters most right now, not novelty.
  2. Each week: add 5–10% load on the main strength lifts once every rep is clean, and extend the Saturday long run by 5–10 min if you're recovering well.
  3. After week 4, reassess: how did Sunday's class feel relative to your lifting and running? If transitions are the limiter, ask the coach for extra work there. If the runs are the limiter, bias more Zone 2 volume during the week.
  4. Once you pick a race date, this shifts into a real periodized build — base, build, peak, taper — with pace targets built from your own splits instead of effort-based prescriptions.
Scope note: this covers training and technique only. Nutrition, sleep, and recovery protocols aren't addressed here — for calorie needs at this training volume, that's a sports nutritionist's call, not mine. If anything above produces pain (not normal training fatigue), stop and see a physio before working around it.

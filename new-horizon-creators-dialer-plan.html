01 · The Role

What the Dialer Does (and Doesn't)

One job: turn old pipeline into booked calls for closers. They don't close, don't take payments, don't touch active students.

04 · Data

How the Data Gets Set Up in GHL

The rule: the dialer never overwrites the original sales pipeline. We already lost trust in the numbers once. Reactivation gets its own lane so the main dashboard stays clean.

Build these before day 1

1
A separate "Reactivation" pipeline
Stages: To Dial → Attempting → Connected → Booked → Showed → Closed / Lost / Nurture. Leads get added here; their original stage in the Sales Pipeline stays as history.
2
Custom fields on the contact
Reactivation Segment (Deposit, Follow-Up, No-Show, etc.), Dial Attempts (number), Last Dial Date, Last Dial Outcome, Original Closer.
3
One dispo per call, from a fixed list
No Answer · Left VM · Bad Number · Call Back (date) · Not Interested · Not Now (Nurture) · Booked · Routed to $167 · DND. Fixed options only, no free text for the outcome. Notes go in the notes field.
4
Smart lists = the dialer's call queues
One smart list per segment, filtered to: in Reactivation pipeline, Dial Attempts under 6, not DND, Last Dial Date not today. The dialer works the lists top to bottom in priority order.
5
Attribution on every booking
When the dialer books, the Setter field = dialer's name and a reactivation tag goes on the appointment. That's how DPL, show rate and close rate by setter stay accurate, and how we know what this hire actually produced.
6
Clean the list before it's loaded
Dedupe contacts, remove bad / missing phone numbers, strip out the excluded group (Section 02), and attach the last closer note to each lead so the dialer knows the story before calling.

05 · The Cadence

How Each Lead Gets Worked

6 attempts over 14 days, then it moves to Nurture. No lead gets called forever, no lead gets called once and forgotten.

DayAction
Day 1Call. No answer → call back right away (double dial). Still no answer → text
Day 2Call at a different time of day
Day 4Call + voicemail + text
Day 7Call. Text with something useful (a student win, a short clip)
Day 10Call
Day 14Last call + breakup text: "don't want to keep bugging you, reply 'yes' if you still want help." No reply → Nurture
Script angle: it's a reconnect, not a cold call. "Hey [name], you talked with [closer] back in [month] about [their goal from the notes]. Wanted to check in, where are you at with it now?" Can't afford the main program → route to the $167 community, don't drop them.
06 · Onboarding

First Week for the New Dialer

This is the roleplay / certification step Ben and Tyler flagged as missing. Nobody dials live leads until they pass it.

Day 1
  • Access set up (GHL, Slack, TLDV). Walk through the offer, the $167 downsell, and the pipeline
  • Listen to 5 recorded closer calls to learn how prospects talk
Day 2
  • Learn the script + objection handling. Practice the GHL dispo flow on test contacts
Day 3
  • Roleplays with you or a closer: reconnect opener, "no money," "not interested," "call me later," booking
Day 4: Certification
  • Pass a recorded roleplay + a dispo check. Pass = live. Fail = one more day of practice
Day 5
  • Live on the No-Show list only (warmest, smallest). Review every call recording same day
